# v0.0.1-alpha.14

Queued and retained `base_changed` requests can recover across unrelated commits while preserving the immutable approved image and target. Verified open PRs can move onto a newer base with the exact native image bytes and a regenerated inventory fingerprint. The push uses an exact old-head lease. An uncertain push is never replayed automatically.

The controller persists its expected rebase head before pushing. Ship the plugin package, controller and request-backup executable together. Old strict readers cannot read a pending `rebaseHead` field. Downgrade requires disposing of that marker through verified tracking first.
