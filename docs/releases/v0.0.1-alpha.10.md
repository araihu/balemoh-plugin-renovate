# Balemoh Renovate v0.0.1-alpha.10

The writer no longer tries to publish `renovate/stability-days`. Production qualification found that this optional status write prevented opening a PR after the correct branch had been pushed. Commit statuses remain read-only.

Both native profiles set `statusCheckWhen.minimumReleaseAge=never`. Repository release-age checks still decide eligibility, and deferred plans remain blocked. No merge action or automatic recovery replay was added.

SDK, host protocol and Renovate version are unchanged. Existing request records and branches are preserved.
