# Balemoh Renovate v0.0.1-alpha.11

Upgrade list and detail actions now use icons with tooltips. Review links identify the candidate version when several upgrades are available. Details, retained request status, reported PRs and refresh actions share the same accessible link composition.

Tooltips open on keyboard focus and dismiss with Escape. Links retain image/file-specific accessible names, 44px minimum targets and unique table/card/candidate IDs. External PR links announce the new tab and preserve safe navigation attributes. Final PR confirmation keeps its labelled submit action.

Regression tests and the local list/detail preview passed at 390px and 1440px in Goshtoso and Minimal, light and dark. SDK, Goshtoso, host protocol and Renovate versions are unchanged. No collector, writer, credential or merge behavior changed.
