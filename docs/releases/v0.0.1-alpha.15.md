# Balemoh Renovate v0.0.1-alpha.15

When a previously tracked PR disappears from its scoped GitHub lookup, Balemoh marks its checks unknown and keeps the request for review. Tracking can recover when the association returns.

Rebase compares staged image and inventory bytes with the approved content and recomputes the inventory in a fresh checkout. Git attributes that change the approved blob or produce a different inventory stop the rebase before the push.

The plugin, controller, App token refresher and backup tool ship together. Upgrade merges remain manual.
