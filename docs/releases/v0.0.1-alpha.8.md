# Balemoh Renovate v0.0.1-alpha.8

Allow PR tracking with only the controller read token. Request submission still
requires a separate action token, host grant and enabled controller. Equal read
and action tokens remain invalid.

Includes the alpha.7 overview card, list PR states and candidate-review links.
Production requires a host with SDK alpha.4 manifest support. The production
writer remains disabled, the hosted bot stays unchanged and upgrade PR merges
remain manual.
